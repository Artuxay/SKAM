# СКАМ для Windows

Настольное приложение СКАМ на [Electron](https://www.electronjs.org/). Окно открывает сайт https://skam-messenger.ru: интерфейс, сквозное шифрование и вход те же, что в браузере, и обновляются вместе с сайтом. Само приложение — тонкая оболочка: в нём только то, чего не умеет вкладка браузера.

Скачать установщик: **[SKAM-Setup.exe](https://github.com/Artuxay/SKAM/releases/latest/download/SKAM-Setup.exe)** (около 100 МБ, Windows 10 и 11, 64 бит). Ставится без прав администратора в `%LOCALAPPDATA%\Programs\skam-desktop`, ярлыки — на рабочем столе и в «Пуске». Цифровой подписи пока нет, поэтому Windows может предупредить «Система Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».

## Что добавляет приложение

| | |
| --- | --- |
| **Трей** | Крестик прячет окно в трей возле часов — СКАМ продолжает работать: сообщения, звонки, «печатает…». Правой кнопкой по значку: «Запускать вместе с Windows», «Сворачивать в трей при закрытии», «Проверить обновления», «Закрыть СКАМ». С автозапуском приложение стартует сразу в трее. |
| **Уведомления Windows** | Сайт показывает уведомления через service worker; preload подменяет `ServiceWorkerRegistration.prototype.showNotification`, и уведомление показывает Windows (видно и при закрытом окне). Нажатие открывает окно и нужный чат (тем же сообщением `skam-open`, что шлёт service worker). |
| **Непрочитанные** | Сайт пишет число в заголовок — «(3) СКАМ». Приложение рисует его на кнопке панели задач (1…9, «9+») и ставит точку на значок в трее. |
| **Входящий звонок** | Заголовок «📞 Входящий звонок — СКАМ» → окно показывается, не отбирая фокус, кнопка на панели задач мигает. Звонок звенит и при запуске вместе с Windows (`autoplay-policy`). |
| **Рация в других окнах** | Во время звонка в режиме «Рация» и пока окно СКАМ не в фокусе, приложение раз в 20 мс спрашивает у Windows, зажата ли **одна** выбранная клавиша (`GetAsyncKeyState` через [koffi](https://koffi.dev), в фоновом потоке), и передаёт сайту `keydown`/`keyup`. Ввод не перехватывается, другие клавиши не читаются. Сайт отмечает звонок атрибутом `data-call` на `<html>`. |
| **Показ экрана** | Своё окно «Что показать?» (экраны и окна с миниатюрами, без окон самого СКАМ) и переключатель «Звук компьютера» — звук всей системы (`loopback`, только Windows; в нём будут и голоса собеседников). |
| **Ссылки** | Чужие сайты открываются в браузере, статьи и документы СКАМ — отдельным окном приложения, ссылки `?join=…` — в главном окне. Вход через Яндекс ID и VK ID идёт прямо в окне. |
| **Прочее** | Тема заголовка окна — как в СКАМ; меню правой кнопки с проверкой орфографии (русский и английский); масштаб `Ctrl+=` / `Ctrl+-` / `Ctrl+0`; `F11` — во весь экран; `Ctrl+R` — обновить; «Нет связи» с автоповтором; окно запоминает размер и место; второй запуск открывает уже запущенный СКАМ. |
| **Новые версии** | Раз в 6 часов приложение читает https://skam-messenger.ru/desktop.json (`public/desktop.json` в репозитории). Если там версия новее — уведомление и пункт «Скачать СКАМ X.Y.Z» в трее. |

Сайт узнаёт приложение по `window.skamDesktop` (`{ version, platform, pttEverywhere, systemAudio }`, см. `src/lib/desktop.ts`) и по `SKAM-Desktop/<версия>` в User-Agent.

## Файлы

```
desktop/
  package.json              версия приложения, зависимости, настройки сборки (electron-builder)
  src/main.js               главный процесс: окно, трей, уведомления, рация, показ экрана, ссылки, обновления
  src/preload.js            мост с сайтом: window.skamDesktop, уведомления Windows, рация, тема
  src/page-preload.js       окна статей и документов: только window.skamDesktop
  src/ptt.js                рация: клавиша → виртуальный код Windows, опрос GetAsyncKeyState
  src/settings.js           settings.json в %APPDATA%\SKAM: окно, трей, масштаб
  src/picker.*              окно «Что показать?»
  src/offline.*             «Нет связи с сервером»
  src/ui.css                цвета и шрифт СКАМ для окон приложения
  assets/                   иконки (icon.ico, трей, числа для панели задач), шрифт Onest
  scripts/make-icons.mjs    перерисовать иконки из public/favicon.svg (нужен Playwright)
  release-notes.md          текст к выпуску на GitHub
```

Данные приложения — `%APPDATA%\SKAM` (то же, что хранит браузер для сайта, плюс `settings.json`). Удаление программы их не трогает.

## Разработка

Нужен Node.js 22.

```bash
cd desktop
npm install
npm start                                   # окно с https://skam-messenger.ru
npx electron . --url=http://localhost:5173/ # с локальным сайтом (npm run dev в корне)
npx electron . --profile=./tmp-profile      # отдельная папка данных (второй аккаунт)
```

## Выпуск новой версии

1. Поднять `version` в `desktop/package.json` (номер — как у СКАМ, `релиз.неделя.день`) и в `public/desktop.json`.
2. Закоммитить в `main`. Workflow `.github/workflows/desktop.yml` соберёт установщик на Windows и выложит выпуск «СКАМ для Windows X.Y.Z» (тег `desktop-vX.Y.Z`) с файлом `SKAM-Setup.exe`. Ссылка `releases/latest/download/SKAM-Setup.exe` начнёт вести на него, а приложения у людей предложат обновиться, как только сервер соберёт сайт с новым `desktop.json`.

Собрать установщик у себя: `npm run dist` (на Windows; на Linux нужны `wine64` и `wine32`) → `desktop/dist/SKAM-Setup.exe`.

Сборка включает защитные «предохранители» Electron (`electronFuses`): `ELECTRON_RUN_AS_NODE`, `NODE_OPTIONS` и `--inspect` не работают, приложение грузится только из `app.asar` с проверкой целостности.
